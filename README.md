# Converter and Pixel System
This project is written in Python and has 5 parts.

- Part 1 converts user text into ASCII decimal values.
- Part 2 converts a number between binary, octal, decimal, and hexadecimal.
- Part 3 reads an image file called `smiley.png` and writes simplified pixel values to `input.txt`.
- Part 4 reads `input.txt` and generates an image from the pixel values to `output.png`.
- Part 5 tests boundary cases including zero, the largest supported unsigned value, and a negative two's-complement value.

### Requirements:
- Python 3
- Pillow

You can install Pillow with:
```bash
pip install Pillow
```

### To Run:
```bash
python3 hw1.py
```
